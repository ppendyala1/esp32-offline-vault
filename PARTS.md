# Build Steps

1. Program and test the ESP32 over USB.
2. Connect and test the display.
3. Connect the RTC, install its coin cell, and set UTC time.
4. Connect and test the four buttons.
5. Add the LiPo and power switch; test battery operation.
6. Solder the final wiring and mount everything in the enclosure.
